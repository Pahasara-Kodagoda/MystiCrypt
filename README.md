# 🔐 MystiCrypt - Data Encryption & Decryption Tool

MystiCrypt is a lightweight, user-friendly **C++ Windows Forms (CLR)** application designed for securing text using various classical and modern cryptographic techniques. Developed as an Object-Oriented Programming (OOP) project, it provides an intuitive Graphical User Interface (GUI) to seamlessly encrypt and decrypt text.

---

## ✨ Features

- 🔑 **Multiple Cipher Algorithms:**
  - **Caesar Cipher** (Substitution)
  - **Atbash Cipher** (Monoalphabetic)
  - **Substitution Cipher** (Custom key mapping)
  - **Vigenère Cipher** (Polyalphabetic)
  - **Rail Fence Cipher** (Transposition)
  - **Columnar Transposition Cipher**
  - **Simple XOR Cipher** (Symmetric binary bitwise)

- 🎨 **Modern GUI:** Built using Windows Forms for easy interaction.
- 📂 **Documentation Included:** Detailed project documentation provided in PDF format (`MystiCrypt_Documentation.pdf`).
